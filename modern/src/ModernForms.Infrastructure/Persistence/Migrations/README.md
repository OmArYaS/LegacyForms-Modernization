# Migrations

Hand-authored EF Core migrations (the FinTrack pattern): each migration is a
plain C# class in this folder, flagged with `DbContext`/`Migration`
attributes. No snapshot is generated by tooling; the model description lives
in `FormsEntityConfigurations.cs` and migrations are reviewed like code.

Apply on startup: `DatabaseInitializer` runs `MigrateAsync` and seeds the
demo dataset. For production deployments the apply job runs from the
Azure DevOps release stage (`pipelines` in the repo root).
